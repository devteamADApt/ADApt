This is a beta

ADApt is a test version. It can make mistakes and will not find every accessibility problem. It is not a legal compliance certification, so check each corrected file before you use it.

Your original files are never changed unless you choose to replace them. Corrected copies are saved next to them as name_accessible.docx.

What a run looks like

ADApt scans each file, fixes what it can, and then scans the saved copy again to confirm each fix worked. It only counts a fix once the problem is gone.

What it fixes

ProblemWhat ADApt does
No document titleSets one from the document's first heading or line.
No document languageSets the language you choose, so screen readers use the right voice.
Headings that are only big, bold textTurns them into real headings, with levels based on text size.
Tables with no header rowMarks the first row of each table as the header.
Images with no description, or only a file nameQueues a draft description for you to approve, and marks tiny or line-like images as decorative.
Excel links with no textUses the web address as the link text.

A page preview marks each problem with a number that matches the list, and you can edit any title, description, heading or table header afterward. You can check one document or a whole folder at once.

What it does not cover yet

  • PDFs are checked, and ADApt sets their title and language. It does not repair scanned pages or add tags.
  • It does not yet check color contrast, text inside images, links that only say "click here", or lists typed by hand.
  • It only sees images placed in line with the text, not images floating beside it.

Install it

  1. Download the zip file, then right-click it and choose Extract All.
  2. Open ADApt-Beta-Setup.exe and follow the steps.
  3. If Windows says Windows protected your PC, choose More info, then Run anyway. The beta is not code-signed yet.
  4. Open ADApt (Beta) from the Start menu.

To preview Word, PowerPoint and Excel pages, Microsoft Office or LibreOffice must be installed. PDFs preview without either.
